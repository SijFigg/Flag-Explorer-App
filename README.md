# Flag-Explorer-App

A full-stack application for exploring country data and flags. This solution includes:

- A **.NET 8 Web API** for serving country data
- A **React** frontend for displaying the data
- A `docker-compose.yml` setup to run both applications in containers

---

## 🛠 Tech Stack

- **Backend**: ASP.NET Core 8 Web API
- **Frontend**: React (Vite / Create React App)
- **Containerization**: Docker & Docker Compose

##  Getting Started

### Prerequisites

Ensure the following are installed on your system:

- [Docker](https://www.docker.com/)
- [Docker Compose](https://docs.docker.com/compose/)

---

## Running the App with Docker Compose

To build and run the full stack:

```bash
docker-compose up --build
